4. **VM Semantics** — Select / Apply / Merge  
5. **Core Structure** — Orchestration of Tape, Registry, VM

8. **Structural Machine Language (SML)** — SEL / APPLY / MERGE

10. **Distribution Math** — Multi‑tape structural distribution  
11. **External Integration Protocol** — Binding Phoenix to external systems

These clocks form the complete mathematical and architectural definition of Phoenix.
