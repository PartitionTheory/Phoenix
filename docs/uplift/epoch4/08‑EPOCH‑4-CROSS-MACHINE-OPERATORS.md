Phoenix Epoch 4 — Cross‑Machine Operators (Uplift Edition)
Cross‑Machine Operators define how Phoenix maps operator behaviour across machines. All canonical operator notation is preserved.

Phoenix introduces operator mappings that unify behaviour across distributed environments and prepare the system for autonomous distributed lifting in Epoch 5. These operators ensure that transformations applied on one machine remain coherent when extended to another.

Cross‑machine operators are essential for maintaining Phoenix’s distributed synthetic lineage.
