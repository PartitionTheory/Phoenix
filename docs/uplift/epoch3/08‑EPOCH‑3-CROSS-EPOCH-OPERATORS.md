Phoenix Epoch 3 — Cross‑Epoch Operators (Uplift Edition)
Cross‑Epoch Operators define how Phoenix maps operator behaviour across epochs. All canonical operator notation is preserved.

Phoenix introduces operator mappings that unify behaviour across Epochs 1–3 and prepare the system for distributed lifting in Epoch 4. These operators ensure that transformations applied in one epoch remain coherent when extended into another.

Cross‑epoch operators are essential for maintaining Phoenix’s synthetic lineage.
