Phoenix Epoch 13 — Lesson Framework (Uplift Edition)
The Lesson Framework defines how Phoenix structures its synthetic mathematics into explicit lessons. All canonical lesson notation is preserved.

Phoenix introduces framework rules that govern how lessons are formed, how they relate to consolidated structures, and how they propagate through synthetic domains. These rules ensure that lessons maintain coherence with Phoenix’s consolidated mathematics core.

The lesson framework becomes essential for the full lesson curriculum in Epochs 14–17.
